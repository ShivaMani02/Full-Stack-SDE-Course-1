# Shivansh Vasu - YouTube Channel Website

A professional, modern, and fully responsive website showcasing Shivansh Vasu's YouTube channel dedicated to Full Stack Development and Web Technology Tutorials.

## 🎯 Project Overview

This is a single-file HTML project with embedded CSS that creates a beautiful landing page for a tech education YouTube channel. The design features a modern dark theme with cyan accents, smooth animations, and professional styling.

## ✨ Features

- **Modern Dark Theme**: Professional black and dark blue color scheme with cyan accents
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Fade-in effects and hover animations for enhanced user experience
- **Interactive Elements**: 
  - Subscribe button with alert functionality
  - Contact form with validation
  - Social media links section
  - Smooth navigation with sticky header

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No dependencies or build tools required

### Installation

1. Clone or download the project:
```bash
git clone <repository-url>
cd "Full Stack SDE Course 1"
```

2. Open the HTML file in your browser:
   - Double-click `shivansh-vasu-yt.html`, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local server:
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

## 🔧 Customization Guide

### Changing Colors
Edit the CSS to replace colors:
```css
#00d4ff  → Your primary accent color
#0a0e27  → Your dark background
#1a1f3a  → Your card background
```

### Updating Content
1. **Channel Name**: Edit "🎬 Shivansh Vasu" in the header
2. **Tagline**: Update the paragraph below the title
3. **Stats**: Modify numbers in stat cards
4. **About Text**: Edit paragraphs in about section
5. **Tutorials**: Update card titles and descriptions
6. **Social Links**: Replace `#` with actual URLs

### Modifying Animations
- Change animation duration: `0.8s` → `your-duration`
- Edit keyframes for custom animations
- Adjust hover effects (transform, box-shadow)
